# 🚀 Gemini Canvas Web App Collections

Gemini AI를 활용하여 제작한 4가지 웹 애플리케이션 컬렉션입니다. 유틸리티, 게임, 학습, 생활 밀착형 서비스까지 다양한 영역의 결과물을 확인하실 수 있습니다.

## 📱 애플리케이션 목록

### 1. **AlgoLog (알고로그)** 📝

_코딩 테스트 기록의 번거로움을 해결하는 스마트한 동반자_

- **소개**: 문제 링크만으로 정보를 자동 추출하고, 제출한 코드에 대해 AI의 상세한 코드 리뷰와 피드백을 받을 수 있는 기록 플랫폼입니다.
- **주요 기능**: 문제 정보 자동 추출(Link to Info), AI 채점 및 피드백, 활동 잔디(Heatmap) 및 시각화 통계.

### 2. **十二將棋 (십이장기)** ♟️

_지략과 전술이 맞붙는 12칸의 전장_

- **소개**: 유명 예능 '더 지니어스'의 십이장기를 웹으로 구현한 전략 보드게임입니다. 친구와 함께 실시간으로 시점을 공유하며 긴장감 넘치는 대결을 즐길 수 있습니다.
- **주요 기능**: 2인 로컬 대결, 각 플레이어 시점의 화면 구성, 경기 기록 저장 및 복기 기능.

### 3. **모닝빵 (Morning Bbang)** 🥐

_당신의 완벽한 아침을 굽는 루틴 메이커_

- **소개**: 바쁜 아침, 잊기 쉬운 루틴과 소지품을 챙겨주는 생활 보조 앱입니다. 실시간 기상 정보에 맞춰 AI가 오늘 꼭 챙겨야 할 아이템을 추천해줍니다.
- **주요 기능**: 맞춤형 아침 루틴 관리, 실시간 날씨 카드, AI 기반 위치별 외출 필수품 추천.

### 4. **바이브코테 (Vibe Coding Test)** 🔥

_코딩은 AI에게 맡기고, 당신은 논리에만 집중하세요_

- **소개**: 코드를 직접 타이핑하지 않고 문제 해결을 위한 '논리적 설계'만으로 점수를 매기는 새로운 방식의 학습 도구입니다. 사고 과정의 깊이를 AI가 직접 평가합니다.
- **주요 기능**: 난이도별 알고리즘 문제 생성, 텍스트 기반 풀이 방식 채점 및 피드백, 정답 코드 다국어 변환.
